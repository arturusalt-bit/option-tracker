# 📊 Управление опционом — 300 000 USD

Веб-приложение для отслеживания расходов и доходов по опциону 300 000 USD.  
Работает как **PWA** — можно установить на телефон как полноценное приложение.

## 🚀 Живой сайт

👉 **https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/**

> Замените `YOUR_USERNAME` и `YOUR_REPO_NAME` на свои данные после деплоя.

---

## 📱 Установка на телефон (PWA)

### Android (Chrome)
1. Откройте сайт в браузере Chrome
2. Нажмите **⋮** (три точки) → **"Добавить на главный экран"**
3. Подтвердите установку — приложение появится на рабочем столе

### iPhone / iPad (Safari)
1. Откройте сайт в браузере **Safari**
2. Нажмите кнопку **"Поделиться"** (квадрат со стрелкой вверх)
3. Выберите **"На экран «Домой»"**
4. Нажмите **"Добавить"**

## ✨ Возможности

- ➕ Добавление расходов и доходов
- 📊 График динамики по дням (Chart.js)
- 📋 История всех операций с удалением
- 📄 Отчёт за любой период дат
- 📸 Снимок отчёта в PNG
- 💾 Данные сохраняются в localStorage (не теряются при закрытии)
- 📴 Работает офлайн (Service Worker)

## 🌐 Деплой на GitHub Pages

### Шаг 1 — Создайте репозиторий
1. Войдите на [github.com](https://github.com)
2. Нажмите **"New repository"**
3. Введите название, выберите **Public**
4. Нажмите **"Create repository"**

### Шаг 2 — Загрузите файлы
Загрузите все файлы в корень репозитория:
```
index.html
manifest.json
sw.js
icons/
  icon-192.png
  icon-512.png
README.md
```

### Шаг 3 — Включите GitHub Pages
1. Зайдите в **Settings** репозитория
2. Слева выберите **Pages**
3. В разделе **Source** выберите **Deploy from a branch**
4. Ветка: **main**, папка: **/ (root)**
5. Нажмите **Save**

Через 1-2 минуты сайт будет доступен по адресу:  
`https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/`
